## 반갑습니다, 하네스 엔지니어 이태형입니다.

교육기관에서 **서비스 운영과 신규 개발**을 맡고 있습니다.

외주 발주와 관리가 일의 대부분이던 전산 업무를, **안에서 직접 만들고 고치는 개발·운영 조직으로 바꾸었습니다.** 예전 같으면 견적부터 받아야 했던 일을 지금은 직접 만들어 배포합니다.

지금은 혼자서 **운영 중인 LMS·홈페이지 유지보수**와 **신규 프로젝트**를 함께 진행하고 있습니다. 

AI에게 일을 시키기 전에 **AI가 일할 환경을 먼저 설계**하는 **하네스 엔지니어링(Harness Engineering)** 방식으로 일합니다.
